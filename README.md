# MHWS-FilterSOSList (Enhanced Version)

This project is a fork of [mashirochan/MHWS-FilterSOSList](https://github.com/mashirochan/MHWS-FilterSOSList),
licensed under the MIT License.

## About
A Monster Hunter Wilds mod that filters the SOS list based on various customizable parameters such as desired bonus rewards or the maximum of a reward.

## Modifications in this fork
- 최신 게임 버전 대응
- 로직 개선
- 각종 설정 옵션 추가
- 버그 수정
