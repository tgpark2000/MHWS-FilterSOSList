
If you are installing the mod for the first time (and no config file is present), it will automatically read the game's text settings and look for the file matching your language_code first.

The available language_codes from the game options are ja, en, fr, it, de, es, ru, pl, pt-br, ko, zh-hant, zh-hans, ar, es-419, and th.

If you plan to create a language file, we highly recommend naming the file after its corresponding language_code.

Even if you use a file name different from the language_code, it will still display correctly in the combo box menu and can be selected.
